# HTML & CSS Studies

**Estudos, prática e evolução em Front-End**

</div>

---

Este repositório é onde vou registrar minha evolução estudando **HTML e CSS**.

A ideia aqui não é só guardar exercícios ou projetos prontos. Quero usar esse espaço para acompanhar meu aprendizado de verdade: o que aprendi, o que errei, o que tive dificuldade e o que ainda preciso melhorar.

## Sobre os estudos

Estou começando novamente pela base, mesmo já tendo algum conhecimento de HTML e CSS.

Quero ter certeza de que realmente entendo os fundamentos antes de começar a depender de soluções mais avançadas.

Durante os estudos, vou praticar coisas como:

- HTML semântico;
- CSS;
- organização de páginas;
- tipografia;
- cores e espaçamento;
- Flexbox;
- Grid;
- responsividade;
- acessibilidade;
- UI e UX;
- princípios de design;
- transições e animações;
- organização e manutenção do código.

Conforme eu avançar, os exercícios também vão ficando mais complexos.

## Como estou estudando

Não quero simplesmente copiar códigos e decorar propriedades.

A ideia é:

**pensar → pesquisar → tentar → errar → entender o erro → corrigir → documentar.**

Nem sempre vou saber a solução antes de começar, e isso faz parte do processo.

Quero aprender a pesquisar, consultar documentação e descobrir sozinho como resolver um problema antes de procurar uma resposta pronta.

## Exercícios

Os exercícios serão feitos de forma progressiva.

Vou começar com coisas bem simples e, aos poucos, juntar os conhecimentos anteriores para criar interfaces e projetos mais completos.

Um exercício novo não significa esquecer o anterior. A intenção é continuar usando conhecimentos antigos enquanto novos conceitos são adicionados.

Também quero trabalhar bastante a parte de **design, UI, UX e responsividade**, porque não quero aprender apenas a fazer o código funcionar. Quero aprender a construir interfaces que façam sentido visualmente e para quem vai utilizá-las.

## Documentação

Sempre que possível, vou documentar os exercícios e projetos.

Quero registrar:

- o que o exercício pedia;
- como interpretei o problema;
- quais decisões tomei;
- o que precisei pesquisar;
- os erros que encontrei;
- como consegui resolver;
- o que aprendi;
- o que ainda não entendi completamente.

Não quero esconder os erros.

Se alguma coisa não funcionou ou se eu precisei pesquisar bastante para resolver, isso também faz parte da minha evolução e merece ser registrado.

## Estrutura

```text
html-css-studies/
├── exercises/
├── projects/
├── notes/
├── challenges/
└── README.md
```

### `exercises/`

Exercícios práticos para desenvolver e reforçar os conhecimentos de HTML e CSS.

### `projects/`

Projetos maiores onde vou juntar diferentes conhecimentos em uma mesma aplicação.

### `notes/`

Anotações e conteúdos que eu precisar revisar ou entender melhor.

### `challenges/`

Desafios que exigem mais pesquisa, raciocínio e tentativa até chegar em uma solução.

## Objetivo

Meu objetivo com esse repositório é construir uma base realmente sólida em Front-End.

Não quero ter apenas uma lista de tecnologias no currículo.

Quero conseguir olhar para um problema, entender o que precisa ser feito, pesquisar quando não souber, testar possibilidades e conseguir explicar por que escolhi determinada solução.

Este repositório vai ser o registro desse processo.

**Ainda estou aprendendo. E a ideia é que esse repositório mostre justamente essa evolução.**
